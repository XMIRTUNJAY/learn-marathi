# Marathi Games — Design Spec

Date: 2026-10-10
Status: Approved design pending spec review
Site: https://xmirtunjay.github.io/learn-marathi/ (repo: `blog/learn-marathi`)

## 1. Goal

Add five genuinely playable, static, SEO-indexable Marathi games to the existing
Bol Marathi Astro site, reusing its layout, design tokens, data and build
pipeline. Product principle: **the website teaches; practice makes it stick.**
No login, no backend, no API keys. Local progress via browser storage with
graceful fallback.

## 2. Repository evidence (audit summary)

- **Framework:** Astro 7 static (`astro build` → `dist/`), npm, Node ≥22.12
  (local: v22.12.0). `site: 'https://xmirtunjay.github.io'`, `base:
  '/learn-marathi'`, `trailingSlash: 'always'`, `viewTransitions: true`,
  `@astrojs/sitemap` (build-date lastmod), MDX.
- **Layout:** `src/layouts/Base.astro` (BaseHead + SiteHeader + SiteFooter +
  MilestoneToast + skip-link + shortcuts modal). Design tokens:
  `src/styles/design-system/tokens.css` — terracotta `#8E2D12`, cream
  `#FDFBF7`, Mukta + Noto Sans Devanagari, spacing/radius/shadow/motion
  scales, reduced-motion respected. Global classes: `.prose`, `.kicker`,
  `.lede`, `.btn`, `.card`, `.card-grid`, `.chip`, `.tok`.
- **Nav:** `SiteHeader.astro` — grouped nav (Learn / Practice / Explore) +
  direct links. `siteUrl()` (`src/lib/site.ts`) is the base-aware, trailing-
  slash URL helper used everywhere.
- **Data:** `src/data/learn/vocab.json` — 1167 words, schema `{id, marathi,
  hindi, english, transliteration, category, exampleMarathi, exampleHindi,
  exampleEnglish, note, noteEn}`, 34 categories. `units.json` — 31 units × 6
  lessons incl. 186 `sentenceBuilder` rows `{lesson, prompt, promptEn, tokens,
  answer, hindi, hindiEn}`. Content QA gates (`tools/validate-content.mjs`,
  `tools/qa.mjs`) run in `prebuild`/CI.
- **Audio:** `audio-manifest.json` is empty ("no TTS credentials"). Audio
  today = device TTS via `speechSynthesis` (`SayScript.astro`: self-guarding
  `.say` buttons, mr voice → hi fallback → removes itself if unsupported).
  **New:** the site owner has an original synthesized SFX pack (74 mono MP3s,
  ~0.8 MB, generated by their own `make_sfx.py` scripts — no external
  licensing): `ui` (click, whoosh, pop, game_start…), `feedback` (correct,
  correct_soft, incorrect, hint, try_again…), `streak` (streak_1..6,
  streak_lost, combos), `reward` (coin, stars, level_up, new_high_score…),
  `fanfare` (round_complete, game_complete, game_over, perfect_score),
  `sentence_builder` (word_pick/place/remove, sentence_correct/wrong…).
  Games use these SFX + device TTS for spoken Marathi.
- **Tests:** no unit-test framework. Playwright devDep + root `*.test.ts`
  harnesses + `tools/*.mjs` verification scripts. CI (`deploy.yml`): `npm ci`
  → `npm run qa` → withastro/action build → deploy.
- **Existing practice (must not duplicate):** quiz pages (10-Q word-meaning
  MCQ + tap-to-arrange sentence mode), SRS review (IndexedDB via `idb`),
  QuickPractice, SentenceBuilder, Anki decks. localStorage keys
  `bol-marathi-*`; `AnalyticsEvents` + `data-funnel` hooks; AppCTA pattern.
- **Overlaps:** quiz "arrange" mode overlaps Sentence Scramble → new game
  reuses `sentenceBuilder` data but adds drag/keyboard reordering, multiple
  accepted solutions, hints, pattern explanation, difficulty. Picture art
  lives in `public/og/*.webp`, mascot SVGs in `public/mascot/*.svg`.

## 3. Architecture (Approach A — Astro-native static pages + shared TS modules)

### 3.1 Routes (static, trailing slash, existing Base.astro layout)

- `/games/` hub
- `/games/marathi-wordle/`
- `/games/picture-guess/`
- `/games/marathi-crossword/`
- `/games/word-chain/`
- `/games/sentence-scramble/`

All built with `getStaticPaths()` where dynamic (crossword puzzles may use
`[puzzle]` only if more than one page per game; v1 keeps one page per game
with puzzles selected in-page). Existing routes untouched.

### 3.2 Pure logic modules (`src/lib/games/`)

No JSON imports inside these modules — data passed in as arguments — so
`node --test` runs them directly.

- **`graphemes.ts`** — one definition of a "letter" for all games: the
  **akshara (grapheme cluster)**. `Intl.Segmenter('mr', {granularity:
  'grapheme'})` when available, tested fallback (codepoint cluster via
  Unicode property regex) otherwise. Functions: `splitGraphemes(word)`,
  `countGraphemes(word)`, `normalizeMr(word)` (NFC), `isMarathi(word)`
  (Devanagari block check). `बाई` → 2 tiles (बा, ई); `शब्द` → 3 tiles
  (श, ब्, द). Never `split("")` or naive indexing.
- **`daily.ts`** — UTC-date-seeded deterministic pick from a versioned list:
  `dailyIndex(dateISO, version, length)` = stable hash of `dateISO +
  ':' + version` mod length. Same puzzle for every visitor all day; refreshes
  never reroll; bumping `version` reshuffles the whole list.
- **`wordle.ts`** — `evaluateGuess(answer, guess)` on NFC-normalized akshara
  sequences → per-akshara states `correct | present | absent`; share-grid
  renderer (`🟩🟨⬜`-style, row strings only — never the answer or the word).
- **`chain.ts`** — rule (§4.4), duplicate detection, `suggestNext` from the
  curated dictionary.
- **`storage.ts`** — `loadState(key)`/`saveState(key, value)` with try/catch →
  in-memory fallback; keys prefixed `bol-game-`. Never throws.
- **`sfx.ts`** — shared sound-effect player for the owner's synthesized SFX
  pack (`public/games/audio/<category>/<id>.mp3`): lazy Audio objects per id,
  rewind-to-0 before replay, `play(id)` no-ops when muted, unsupported, or
  the file fails to load; mute toggle persisted (`bol-game-muted`). All
  sounds fire after user interaction (no autoplay issues).
- **`content.ts`** — build-time loaders/validation: resolve game-data ids to
  `vocab.json`, required fields present, grapheme counts match declared
  counts, crossword intersections valid, chain dictionary playable, scramble
  accepted solutions non-empty. Wired into `prebuild` so bad data fails the
  build (same philosophy as existing content QA).

### 3.3 Shared UI components (`src/components/games/`)

- **`GameShell.astro`** — page frame inside Base: kicker + h1, "All games"
  back link, sibling-game nav, `<slot>`. Uses existing `.prose` widths.
- **`GameIntro.astro`** — accessible instructions in `<details>` (open by
  default on first visit).
- **`HintBox.astro`** — progressive hints with `aria-live="polite"`.
- **`GameResult.astro`** — consistent end screen: score/streak, word or
  sentence meanings (EN + HI when available), related-lesson links,
  AppCTA (existing component, non-intrusive), replay button.
- **`SayBtn.astro`** — reuses the existing `speechSynthesis` pattern
  (`.say`, mr → hi voice, removes itself when unsupported). No audio files.

### 3.4 Game data (`src/data/games/`)

- **`wordle.json`** — `{ version, answers: [vocab ids], practicePool: [ids] }`.
  Answer words: 3–5 aksharas, pre-validated.
- **`picture-guess.json`** — `{ items: [{ id: vocab id, level: easy|medium|challenge, svg: filename }] }`.
- **`crossword.json`** — curated puzzles with grid + clues, validated
  intersections.
- **`chain.json`** — curated chainable dictionary (vocab ids) + rule metadata.
- **`scramble.json`** — `{ items: [{ sentenceBuilderRef, accepted: [token
  arrays], difficulty }] }` referencing existing curriculum rows.

## 4. The five games

### 4.1 Marathi Wordle — `/games/marathi-wordle/`

- 6 attempts. Guess unit = akshara (grapheme cluster) — never byte/codepoint.
- On-screen Devanagari keyboard + physical keyboard via transliteration map;
  backspace + enter.
- States: correct (green) / present (amber) / absent (neutral), with
  reduced-motion-safe flip animation.
- **Daily challenge:** UTC-date-seeded from versioned answer list (§3.2
  `daily.ts`). One per day per visitor; completion stored in localStorage.
- **Practice mode:** random word from the practice pool, unlimited plays —
  clearly separated from the daily challenge.
- Reveal on finish: word, transliteration, EN + HI meaning, example sentence,
  `.say` audio.
- **Share:** emoji grid (⬜/🟨/🟩 rows) + "Bol Marathi Wordle #N" header —
  no answer leakage. `navigator.clipboard` with fallback.
- Answers: ~60 curated vocab words, 3–5 aksharas, grapheme counts validated
  at build.

### 4.2 Picture Guess — `/games/picture-guess/`

- ~40 items across easy / medium / challenge (curated from vocab.json:
  food, animals, home, weather, colors, clothing — unambiguously drawable).
- Each item renders a hand-authored SVG from `public/games/picture-guess/`.
  **Deliverable: `docs/GAMES_SVG_PROMPTS.md`** — table of filename, word,
  level, generation prompt, settings (200×200 viewBox, flat fills, warm
  palette #8E2D12/#2E7D5B/#B8860B, no gradients, no text). SVGs are built
  from this table; game falls back to a labeled placeholder card if a file
  is missing (never a broken image).
- Progressive hints: definition (English gloss) → transliteration → first
  akshara.
- Answer: MCQ of 4 Marathi words (rendered as styled cards with Devanagari).
- Score + streak; audio after answering (`.say`); keyboard + touch.

### 4.3 Marathi Crossword — `/games/marathi-crossword/`

- 2 hand-curated puzzles, 6–8 words each, validated intersections (every
  crossing akshara matches in both directions — validated at build and in
  tests).
- One akshara per cell (same grapheme unit as Wordle).
- Across/down clue lists; click a cell to select; arrow keys navigate,
  typing fills, backspace clears.
- Check answers + reveal-letter hint; meanings + example sentences on
  completion.
- Responsive: grid scales with viewport; clues stacked below on mobile.

### 4.4 Word Chain — `/games/word-chain/`

- **Documented rule:** the next word's **first akshara** must equal the
  previous word's **last full akshara** (e.g., घर → र… → रंग; बाई → ई…).
  The rule is stated in the game intro and tested.
- Curated dictionary from vocab.json, grouped by first akshara; validated at
  build: every starting akshara that can occur has ≥1 continuation.
  **Reliable curated challenge mode — not claimed to cover every Marathi word.**
- Solo endless play: score/streak, duplicate prevention, invalid submissions
  rejected with explanation ("needs र…").
- "Stuck?" hint suggests a valid word; end condition = no valid continuation
  remains for the current ending (game acknowledges completion of a run).

### 4.5 Sentence Scramble — `/games/sentence-scramble/`

- Tiles from verified `sentenceBuilder` rows (reused from `units.json` via
  build-time selection — no copied content).
- Arrange tiles into the correct sentence: tap-to-place (existing `.tok`
  pattern), drag-and-drop (pointer events), and keyboard reorder (arrow keys
  move the focused tile).
- Check against an **accepted-solutions array**: the curriculum's canonical
  order plus alternatives where grammar permits (e.g., optional leading
  time/place words). Never assumes a single valid word order.
- EN + HI translation shown; brief pattern explanation after check (from
  `prompt`/`promptEn` pattern line).
- Hints (first tile placement / pattern reminder), score, difficulty by
  token count (3–4 easy, 5–6 medium, 7+ challenge).

## 5. Content quality & curriculum integration

- Reuse `vocab.json` and `units.json` (the authoritative synced snapshots).
  Game data references entries by their existing `id`s — no copied lists per
  game; reusable data stays centralized in `src/data/games/*.json`.
- All new content carries provenance: SVG illustrations are original
  (this repo, `public/games/picture-guess/`, prompt table in
  `docs/GAMES_SVG_PROMPTS.md`); game datasets cite the vocab ids they use.
- Validation at build: required fields, Unicode (NFC + Devanagari block),
  duplicate rejections, id resolution, grapheme-count consistency.
- **Language-audit honesty:** game copy states content comes from the Bol
  Marathi curriculum; it does NOT claim native-speaker audit of game
  wrappers. Uncertain linguistic entries (e.g., word-chain continuation
  claims, alternative word orders) are flagged in §9 for human review.

## 6. Site integration

- `SiteHeader`: "Games" link in the Practice group (after Quizzes).
- Homepage: one games card-grid section (alternating-surface rhythm
  preserved).
- `/games/` hub: 5 cards with one-line descriptions + difficulty labels.
- Contextual links (small, non-intrusive): vocabulary cluster pages →
  Wordle + Picture Guess; sentence-structure/grammar pages → Sentence
  Scramble; quiz completion → try a game. No repetitive promotion.
- Game result screens link back to related lessons (existing
  RelatedContent/related-link patterns) + AppCTA.

## 7. Design & UX

- Reuse existing visual identity and tokens — calm, warm, playful
  educational style; no separate design system.
- Strong hierarchy, excellent mobile usability, large touch targets
  (≥44px), fast loading (no new runtime deps), clear correct/incorrect
  feedback, short rounds, immediate educational value.
- Reduced-motion support everywhere (existing tokens + explicit overrides),
  keyboard accessibility (focus-visible, logical tab order, `aria-live`
  feedback).

## 8. Testing & validation

- **node:test** suites in `tests/` (run via `npm test` =
  `node --test --experimental-strip-types tests/`):
  grapheme segmentation + NFC normalization; Wordle evaluation + daily
  determinism; chain rule + duplicate rejection; crossword grid/clue
  validation; scramble accepted solutions; storage fallback; content schema
  validation; scoring/completion states; base-path-aware link helpers;
  storage failure and recovery (including the SFX mute fallback).
- Content validation wired into `prebuild` (bad game data fails the build).
- `npm test` added to the CI `qa` job.
- **Playwright** (extend the existing root-harness pattern): load all 6
  routes at desktop (1280×800) and mobile (390×844); complete one full round
  per game; restart/replay; back/forward navigation; console errors; failed
  network requests.
- Manual verification: `npm run build`, `npm test`, `npm run qa`, production
  asset paths under `/learn-marathi/`.

## 9. Known limitations & human-review flags

- Spoken Marathi is device-TTS only (real voice files would need the owner's
  `make_marathi_voice.py` + internet); SFX are the owner's synthesized pack.
  Games degrade silently when audio is unsupported.
- Word-chain dictionary is curated, not exhaustive; chain continuations are
  validated structurally (first-akshara matches), but linguistic
  appropriateness of every suggested continuation needs a native-speaker
  pass. Flagged in game copy ("curated challenge").
- Sentence Scramble alternative word orders are conservative (only clearly
  grammatical permutations accepted); broader alternatives need a
  native-speaker pass.
- Picture Guess SVGs are hand-authored originals (~40 words); the prompt
  table is the build source. Ambiguity (a picture matching more than one
  vocab entry) is checked against the curated list at build time.
- Game content is curriculum-sourced and machine-validated; it is not
  claimed to be native-speaker audited.

## 10. SEO & deployment

- Unique titles + meta descriptions for the hub and each game page
  (existing "| Bol Marathi" title pattern).
- Canonical URLs automatic via BaseHead; sitemap auto-includes new routes;
  breadcrumbs from the existing `crumbs` prop. No new structured data
  beyond what Base already emits.
- Production build + GitHub Pages assumptions verified via `npm run build`
  + `npm run preview` + Playwright against built output.
- No deploy/push without explicit authorization.
